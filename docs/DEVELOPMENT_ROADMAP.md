# Minecraft 一比一复刻 — 开发路线图与进度追踪

> **目标**: 将当前项目逐阶段推进至 Minecraft Java Edition 1.20.1 玩法与观感对等
> **技术栈**: React 18 + TypeScript + Vite 4 + Three.js (WebGL)
> **更新规则**: 每个阶段完成后更新本文档进度，任何功能范围变更须同步修改

**多人联机当前发现（2026-06-21）**:
- 可用链路：`npm run server` 可启动 Node.js WebSocket 服务端，默认监听 `ws://localhost:8080`；客户端多人菜单默认连接该地址；握手验证已收到 `S2C_JOIN_ACK`。
- 已覆盖能力：玩家加入/离开、移动同步、聊天、区块请求、挖方块、放方块、基础怪物移动/状态、掉落物、投射物服务端 tick、时间与天气广播。
- 已修复问题：单人模式的 `mock://local` 连接不再被当作多人权威连接，避免本地箭矢、怪物、掉落物和伤害循环被跳过。
- 主要缺口：多人模式中弓箭/雪球/鸡蛋/末影珍珠/钓鱼竿/三叉戟/烟花等右键物品动作尚未完整发送到服务端；背包、耐久、饥饿、死亡、维度、容器和存档仍缺少完整服务端权威与持久化；公网部署需要 `wss://` 反代与连接配置说明。
